## 1. Общая концепция

**Shadow Cards** (карты тени / карты событий) — это случайные события, которые происходят с караваном игрока каждый ход. Каждый ход система автоматически вытягивает одну карту из колоды и применяет её эффект.

### Ключевые принципы

| Принцип | Описание |
|---------|----------|
| **Автоматичность** | Карта вытягивается без действия игрока в начале каждого хода |
| **Случайность** | Карты выбираются случайно с учётом веса и условий |
| **Последствия** | Эффекты могут быть положительными, отрицательными или нейтральными |
| **Временность** | Некоторые эффекты длительные (на N ходов), другие мгновенные |
| **Отмена** | Игрок может отменить карту с помощью специальной карты руки (CancelCard) |

### Два типа карт в колоде

```
Каждый ход:
├── Battle Card (30% базовый шанс) → Битва с врагом
└── Shadow Card (70% базовый шанс) → Событие/эффект
```

## 3. Типы карт

### 3.1 ShadowCardData (карта тени)

ScriptableObject, хранящий данные события.

#### Поля

| Поле | Тип | Описание | Пример |
|------|-----|----------|--------|
| `cardID` | `int` | Уникальный ID карты | `1` |
| `cardName` | `string` | Название карты | `"Найденный кошель"` |
| `description` | `string` | Описание события | `"На обочине дороги блестит..."` |
| `minDifficulty` | `int` (0-10) | Мин. сложность для появления | `0` |
| `maxDifficulty` | `int` (0-10) | Макс. сложность для появления | `10` |
| `weight` | `int` (1-100) | Вес для случайного выбора | `15` |
| `effectType` | `ShadowEffectType` | Тип эффекта | `Money` |
| `value` | `int` | Числовое значение эффекта | `10` |
| `isTemporary` | `bool` | Длительный эффект? | `false` |
| `duration` | `int` (1-10) | Длительность в ходах | `1` |
| `penaltyValue` | `int` | Доп. штраф (для Confiscation) | `200` |

#### Пример в инспекторе

```
[ShadowCardData] Shadow_001_NayденныйКошель
├── Идентификация
│   └── Card ID: 1
├── Основное
│   ├── Card Name: Найденный кошель
│   └── Description: На обочине дороги блестит что-то в песке...
├── Условия появления
│   ├── Min Difficulty: 0
│   ├── Max Difficulty: 10
│   └── Weight: 15
├── Эффект
│   ├── Effect Type: Money
│   └── Value: 10
├── Временность
│   ├── Is Temporary: false
│   └── Duration: 1
└── Дополнительно
    └── Penalty Value: 0
```

## 5. Условия появления

### 5.1 Сложность (Difficulty)

Каждая карта имеет диапазон сложности `[minDifficulty, maxDifficulty]`. Карта может появиться только если текущая сложность хода попадает в этот диапазон.

```
Текущая сложность хода = 5

Карта A: min=0, max=3  →  НЕ появится (5 > 3)
Карта B: min=2, max=7  →  МОЖЕТ появиться (2 ≤ 5 ≤ 7)
Карта C: min=8, max=10 →  НЕ появится (5 < 8)
```

### 5.2 Вес (Weight)

После фильтрации по сложности карты выбираются случайно с учётом веса.

```
Допустимые карты:
├── Карта A: weight = 15
├── Карта B: weight = 10
└── Карта C: weight = 5

Общий вес = 30
Вероятность A = 15/30 = 50%
Вероятность B = 10/30 = 33%
Вероятность C = 5/30 = 17%
```

### 5.3 Тип колоды (Battle vs Shadow)

```
Базовый шанс Battle = 30% (baseBattleChance)

Модификаторы:
├── Сложность: difficultyToBattleChance curve
│   └── Например: при сложности 5 → шанс 40%
├── Доп. условия: extraConditions
│   └── Например: в тумане → шанс Battle × 0.5
└── Итоговый шанс = base × curve × conditions
```

## 6. Эффекты карт

### 6.1 Типы эффектов

| Тип | Описание | Параметр `value` | Временный? |
|-----|----------|------------------|------------|
| `Money` | Изменение динаров | Сумма (+/-) | Нет |
| `Attack` | Изменение атаки каравана | Бонус/штраф | Да |
| `Capacity` | Изменение грузоподъёмности | Бонус/штраф | Да |
| `Bargain` | Изменение торговли | Бонус/штраф | Да |
| `AddGoods` | Добавить товар | Количество | Нет |
| `RemoveGoods` | Удалить товар | Количество | Нет |
| `FireCrewMember` | Уволить члена команды | — | Нет |
| `WagePenalty` | Двойное жалованье | — | Нет |
| `Confiscation` | Конфискация + штраф | — | Нет |
| `TeamStats` | Все характеристики команды | Множитель % | Да |
| `BonusTrade` | Бонус к цене продажи | % | Нет |

### 6.2 Примеры эффектов

#### Деньги

| Карта | `value` | Результат |
|-------|---------|-----------|
| Найденный кошель | `+10` | `+10%` к текущему капиталу |
| Пошлина у моста | `-20` | `−20%` от текущего капитала |
| Азартный шейх | `+50` | Выбор: рискнуть (+50% / −50%) или отказаться |

#### Цены товаров (BonusTrade)

| Карта | `value` | Результат |
|-------|---------|-----------|
| Слух с рынка | `+10` | `+10%` к цене одного товара в следующем городе |
| Перекупщики | `-25` | `−25%` к цене одного товара |
| Праздник урожая | `+45` | `+45%` ко всем товарам (разово) |

#### Груз и трюм

| Карта | `effectType` | `value` | `isTemporary` | `duration` |
|-------|-------------|---------|---------------|------------|
| Крепкие тюки | `Capacity` | `+10` | `true` | `10` |
| Подмокший груз | `RemoveGoods` | `1` | `false` | `1` |
| Верблюд оступился | `RemoveGoods` | `2` | `false` | `1` |

#### Состав команды

| Карта | `effectType` | `value` | `isTemporary` | `duration` |
|-------|-------------|---------|---------------|------------|
| Второе дыхание | `TeamStats` | `+10` | `true` | `10` |
| Простуда | `TeamStats` | `−20` | `true` | `10` |
| Зов старой жизни | `FireCrewMember` | `0` | `false` | `1` |

### 6.3 Временные эффекты

Временные эффекты (`isTemporary = true`) действуют указанное количество ходов, затем автоматически снимаются.

```
Ход 1: Карта "Крепкие тюки" → +10% вместимости, duration=10
Ход 2-10: Эффект активен
Ход 11: Эффект автоматически снимается
```

## 7. Процесс розыгрыша

### 7.1 Последовательность

```
1. GameManager вызывает CardManager.DrawCard(difficulty)
   │
2. CardManager проверяет CancelCard
   │── Если активен → карта отменяется, анимация "[Отменено]"
   │
3. CardManager выбирает тип колоды (Battle vs Shadow)
   │── ResolveDeckType(difficulty, conditions)
   │
4. Фильтрация карт по сложности
   │── minDifficulty ≤ current ≤ maxDifficulty
   │
5. Взвешенный случайный выбор
   │── WeightedRandom(validCards)
   │
6. Добавление карты в UI колоду
   │── deckUI.AddCard(card)
   │
7. Анимация флипа
   │── deckUI.DrawAndShowTopCard()
   │── Появление → Пауза → Флип → Показ лица
   │
8. По завершении анимации → маршрутизация
   │── Shadow → ShadowEffectManager.ApplyCard()
   │── Battle → BattleManager.PrepareBattle()
   │
9. Карта уходит в сброс
   └── deckUI.DiscardCurrentCard()
```

### 7.2 Сброс и перетасовка

```
Колода (Queue<ICard>)          Сброс (List<ICard>)
┌─────────┐                    ┌─────────┐
│ Card A  │──draw──→ revealed  │         │
│ Card B  │                    │ Card A  │
│ Card C  │                    │ Card B  │
└─────────┘                    └─────────┘

Когда колода пуста:
Сброс → перетасовка → новая колода
```

## 8. UI и анимация

### 8.1 Префаб карты (CardDisplay)

```
CardDisplay (RectTransform)
├── Image [cardBackImage]          ← рубашка (единый спрайт)
└── CardFace (GameObject)
    ├── Image [cardFaceImage]      ← фон лица (единый спрайт)
    ├── TextMeshPro [titleText]    ← название карты
    ├── TextMeshPro [descriptionText] ← описание
    └── Image [typeIcon]           ← иконка типа (опционально)
```

### 8.2 Анимация флипа

```
Phase 1: Появление (0.25s)
    Scale: 0 → 1

Phase 2: Пауза (0.2s)
    Показ рубашки

Phase 3: Флип (0.5s total)
    3a: Scale X: 1 → 0  (0.25s) — рубашка схлопывается
    3b: Переключение на лицевую сторону
    3c: Scale X: 0 → 1  (0.25s) — лицо разворачивается

Phase 4: Событие OnCardRevealed
    → вызов эффекта/битвы
```

### 8.3 Отменённая карта

```
Оригинал: "Найденный кошель"
Отменена: "[Отменено] Найденный кошель"

Визуально: та же карта, но с префиксом [Отменено]
Эффект: не применяется
```

## 9. Импорт из CSV

### 9.1 Формат CSV

**Файл:** `Assets/Data/ShadowCards.csv`

**Разделитель:** запятая (`,`) или табуляция (`	`)

**Кодировка:** UTF-8

#### Заголовки колонок

```csv
ID,Name,Description,EffectType,Value,IsTemporary,Duration,MinDifficulty,MaxDifficulty,Weight,PenaltyValue
```

| Колонка | Тип | Обязательная | Описание |
|---------|-----|--------------|----------|
| `ID` | `int` | Да | Уникальный ID |
| `Name` | `string` | Да | Название карты |
| `Description` | `string` | Да | Описание события |
| `EffectType` | `enum` | Да | Тип эффекта |
| `Value` | `int` | Нет | Числовое значение (default: 0) |
| `IsTemporary` | `bool` | Нет | Длительный? (default: false) |
| `Duration` | `int` | Нет | Длительность (default: 1) |
| `MinDifficulty` | `int` | Нет | Мин. сложность (default: 0) |
| `MaxDifficulty` | `int` | Нет | Макс. сложность (default: 10) |
| `Weight` | `int` | Нет | Вес (default: 10) |
| `PenaltyValue` | `int` | Нет | Штраф (default: 200) |

## Приложение: Глоссарий

| Термин | Описание |
|--------|----------|
| **Shadow Card** | Карта события/тени — случайное событие в пути |
| **Battle Card** | Карта битвы — бой с врагом |
| **Difficulty** | Сложность хода (0-10), влияет на доступные карты |
| **Weight** | Вес карты для случайного выбора |
| **EffectType** | Тип игрового эффекта (Money, Capacity и т.д.) |
| **Temporary** | Длительный эффект (на N ходов) |
| **CancelCard** | Карта руки, отменяющая розыгрыш |
| **Flip** | Анимация переворота карты (рубашка → лицо) |
| **Discard** | Сброс карты в отбой после розыгрыша |
