# Support

Below is how to access help, report issues, and receive updates for **Summon Style: Hardline**.

---

## Official Support Channels

Hardline is developed and maintained by **SummonBox Studio**.

All official support is handled through:

- **Website**  
  [https://summonboxstudio.com](https://summonboxstudio.com)

- **Documentation Portal**  
  [https://summonboxstudio.com/docs/smnstylehardline](https://summonboxstudio.com/docs/smnstylehardline)

- **Support Desk**  
  [https://summonboxstudio.com/support](https://summonboxstudio.com/support)

These are the only guaranteed channels for:
- Bug reports  
- Technical help  
- License questions  
- Updates and patches  

Support requests made through third-party marketplaces or social platforms are not guaranteed to be answered.

---

## Before Requesting Support

Before submitting a support request, verify:

- You are using a supported Unity version  
- You are using URP 14+  
- Linear color space is enabled  
- Depth Texture and Opaque Texture are enabled in the active URP renderer  
- The Hardline Wizard's `Core` tab has been inspected  

Most rendering issues come from missing one of these requirements.

See:

→ [Requirements](Setup/Requirements.md)  

→ [Installation](Setup/Installation.md)

---

## What Is Covered

We provide support for:

- Installation and setup issues  
- URP renderer configuration  
- Hardline shaders and materials  
- Style system behavior  
- API usage  
- Demo and sample content  
- Compatibility problems  

We will help diagnose:
- Visual glitches  
- Broken outlines  
- Incorrect lighting or skybox behavior  
- Missing or non-functioning features  

---

## What Is Not Covered

The following are not supported:

- Unity bugs unrelated to Hardline  
- Custom shader graphs not based on Hardline shaders  
- Modified or reverse-engineered Hardline shaders  
- Issues caused by third-party render features  
- Issues caused by custom URP pipelines  
- Cracked, redistributed, or modified package copies  

If you are using a heavily customized URP setup, support may be limited.

---

## How to Submit a Bug Report

When reporting a bug, include:

- Unity version  
- URP version  
- Hardline version  
- A clear description of the issue  
- Steps to reproduce  
- Screenshots or video if visual  
- The affected scene or prefab if possible  

Incomplete reports may not be actionable.

---

## Performance & Platform Issues

Hardline depends on:

- Depth textures  
- Scriptable Render Features  
- Modern URP behavior  

Platforms that lack these (such as WebGL) are not supported.

If performance is a concern, see:

→ [Performance](./Compatibility/Performance.md)
