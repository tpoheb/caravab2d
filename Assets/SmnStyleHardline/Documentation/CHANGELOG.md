# Changelog

## [1.0.0] – 2026-02-05

Initial public release of Summon Style: Hardline.

### Added
- Core Hardline style system
- SSHStyleManager runtime controller
- SSHSystemAsset and SSHStyleAsset presets
- Full URP renderer integration
- Outline rendering system
- Procedural skybox and starfield
- Stylized environment lighting and shadow system
- Hardline shader suite (geometry, water, wind, etc.)
- Setup Wizard for automatic URP configuration
- Demo scene with dynamic day/night cycle
- Sample materials, meshes, and style presets
- Full documentation set

## [1.1.0] – 2026-02-23

Prepping for asset pack products, cleaning up sample assets, and improving the demo scene.

### Added
- Added LOD Levels for all static meshes in the sample assets
- 2 Glass shaders (Speculat and Streaked) added to the core shader suite
- Added new vehicle meshes, materials, and demo content
- Added new style presets to the sample assets
- Added a preset swapper component to the demo scene
- Added UI for the style preset swapper in the demo scene
- UI Icon reworks for all Demo UI
- Improved grass trim in the scene
- Added vehicle to the environment and adjusted the demo scene layout to accommodate it
